# TRUE SMC Content Consolidation

Source-content consolidation layer. Original sources remain evidence; .agents/skills/smc/ remains implementation authority.

## Completion criterion

All materially SMC-relevant methodology, definitions, conditions, exceptions, execution routes, countertrend routes, risk/policy content, and identified source-specific refinements are represented in the categorized layer. Repeated narration, motivational prose, platform boilerplate, and duplicate chart narration are intentionally not copied verbatim.

## Authority rules

1. Original knowledgebase files remain source evidence.
2. Source-specific statements are not silently merged.
3. Examples remain examples unless independently formalized.
4. Later/refined source material is marked as an update where applicable.
5. Unresolved differences remain visible.
6. .agents/skills/smc/ controls implementation semantics.
7. No synthetic evidence or fallback rule is introduced.
