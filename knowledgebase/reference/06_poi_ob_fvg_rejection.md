## Reconciled Order Block model

- Decisional OB is a valid OB that actually causes canonical VALID_BOS.
- Extreme OB is the furthest valid origin-side OB.
- OB validity is based on its own pillars.
- Order Flow state does not automatically invalidate a valid OB.
- A valid Decisional OB may be used while associated OF remains unmitigated, subject to execution gates.

## Rejection Block boundary

Rejection Block is separately typed as a PD-array or execution-location concept.

Source usage of the broad word POI for a Rejection Block is preserved as broad execution-location language, but the canonical typed model does not make RB an OF/OB-equivalent POI class or an automatic Rule-of-Two slot.

This distinction matters when consolidating source passages with overlapping terminology.
