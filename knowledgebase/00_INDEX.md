# TRUE SMC Knowledgebase — Structured Reference Index

The original knowledgebase files remain the evidence corpus. This reference layer groups related material by topic so the source families can be compared and retrieved together.

Canonical implementation authority remains .agents/skills/smc/. These reference files do not replace the canonical skill and do not silently invent methodology rules.

## Reference map

- 01_source_catalog.md — source inventory and classification.
- reference/01_candle_semantics.md — candle anatomy and candle-level observations.
- reference/02_market_structure.md — market structure and structural confirmation.
- reference/03_pullback_retracement.md — pullbacks and retracement qualification.
- reference/04_idm_inducement_liquidity.md — IDM, inducement and liquidity.
- reference/05_bos_choch.md — BOS and CHoCH.
- reference/06_poi_ob_fvg_rejection.md — POI, OB, FVG and Rejection Block.
- reference/07_execution_entries.md — execution and entry models.
- reference/08_risk_targets_policy.md — risk, stops, targets and trading policy.
- reference/09_multitimeframe_countertrend.md — HTF/LTF and countertrend material.

## Reconciliation rule

Where several sources discuss the same concept, the reference files keep the source families visible rather than pretending every wording is identical. Source-specific rules, examples and unresolved differences remain marked as such.

Original source files are not replaced by these summaries.
