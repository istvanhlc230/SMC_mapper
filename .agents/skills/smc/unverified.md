# UNVERIFIED

**Role:** Rules or claims that are present in the methodology context but do not currently have sufficient provenance to be presented as universal SMC facts.

## Current unverified items

- Quantitative definition of `large/high-momentum` unless an authoritative source is established.
- Any newly invented volatility, body-ratio, ATR, or standard-deviation threshold.
- Claims that exact `38.2%` is a universal SMC axiom.
- Claims that the exact `>= 3` opposing-candle rule is universal SMC.
- Claims that the exact `>= 5` prior-extremes condition is universal SMC.
- Claims that the exact three-pillar Order Block model is universal SMC.
- Claims that repository scoring weights are methodology truth.

## Handling rule

Unverified does not mean deleted or automatically false. It means the claim must not be silently promoted to universal or canonical methodology without independent verification and explicit approval.

## Important boundary

An implementation may contain a configurable threshold, but the threshold must be labeled as an implementation parameter unless its methodology status has been established.

## Source of truth

Unverified classification does not replace the canonical rules. Project-specific True SMC methodology remains authoritative in the current semantic-owner documents under `.agents/skills/smc/`, with parameter semantics isolated in `methodology_parameters.md` where applicable.
